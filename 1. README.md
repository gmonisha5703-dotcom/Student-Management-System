# Student Management System

## Project Description
A simple Student Management System developed using Python. It helps users add and view student details.

## Technologies Used
- Python 3

## Features
- Add Student Details
- View Student Details
- Store Student Records
- Simple Menu-Based Interface

## How to Run
1. Install Python 3.
2. Download the project.
3. Run `student_management.py`.
4. Follow the menu options.
